# EMOGERMAN website — with official logo

This folder contains an updated version of the uploaded EMOGERMAN website. It preserves the existing five-language dataset, filters, comparative matrix, research acknowledgements and all 725 expression records. The user-provided medieval-style body-and-soul logo has been integrated into the header and home banner.

## Upload to GitHub Pages

Upload **all three files** to the top level (root) of your existing `emogerman` repository, replacing `index.html` when GitHub asks:

- `index.html` — updated website
- `emogerman-logo.png` — supplied full logo (used in homepage banner)
- `emogerman-icon.png` — small matching logo (used in navigation and browser tab)

Keep the three filenames and their lowercase spellings exactly as written. The HTML references the images using relative paths, so there is no need to configure URLs.

In GitHub, open the `emogerman` repository, select **Add file → Upload files**, drag these files to the upload area, and click **Commit changes**. If updating a file directly using the GitHub interface, ensure the new `index.html` **replaces** the existing one. Verify under **Settings → Pages** that the source is **Deploy from a branch → main → /(root)**.

The published page should appear at `https://jediazvera.github.io/emogerman/` after deployment. If your browser shows an old version, refresh with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
